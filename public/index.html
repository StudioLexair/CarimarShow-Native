EN TU DISPOSITIVO

Elige cómo vivir CarimarShow.

La misma aplicación, en la web y en instaladores con archivos locales.

Android

APK firmado. Contenedor Kotlin con la interfaz incluida y sin registro.

Descargar APK ↓Android 7 o posterior · WebView del sistema disponible

Windows

Instalador x64 con la interfaz, .NET y el instalador offline de WebView2.

Descargar Windows ↓Windows 10/11 x64 · Requiere administrador · Puede mostrar aviso de SmartScreen

Web y iPhone

Abre la app desde tu navegador. En Safari: Compartir → Añadir a la pantalla de inicio.

Abrir versión web ↗La versión web necesita una primera visita con conexión para guardar sus archivos

Las descargas apuntan a la última release publicada. En ella encontrarás los SHA256 de los instaladores. El instalador Windows es grande porque incluye los runtimes.
